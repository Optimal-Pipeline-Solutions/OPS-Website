Technical Brief

OPS Website — Architecture & Operations Guide

Complete technical reference for the optimalpipeline.com static website: how it was built, how it is hosted, how to modify it, and how to deploy changes.
2026-05-31  ·  Owner: Chris Babb

1 What This Is

A single-page static website for Optimal Pipeline Solutions, replacing the existing Wix-hosted site at www.optimalpipeline.com. Apple-inspired design with full-page scroll sections, scroll-triggered animations, and a dark/light theme system.

2 How It Was Built

Session 1 (2026-05-30)

  1. Content scraping — Installed Playwright, wrote headless scrapers that loaded each Wix page with 8–12 second hydration wait, scrolled to trigger lazy content, then extracted all text and images via JavaScript DOM queries. Wix renders everything client-side so WebFetch and requests only get the JS shell — a headless browser is mandatory.
  2. Image download — Pulled the logo, hero background, and section images from the Wix CDN at high resolution. Saved in images/.
  3. Site construction — Built index.html + css/styles.css + js/main.js from scratch using Tailwind CSS (CDN), GSAP + ScrollTrigger (CDN), and Lucide Icons (CDN). No build step required.
  4. GitHub Pages setup — Created the Optimal-Pipeline-Solutions/OPS-Website repo, pushed code, enabled GitHub Pages with legacy deploy-from-branch mode on main.

Session 2 (2026-05-31)

  1. CNAME incident — Added a CNAME file before DNS was flipped, causing a redirect loop. Fixed by removing CNAME and clearing GitHub Pages custom domain settings.
  2. Standardization refactor — Replaced all one-off section classes with a unified component system. Zero visual change, dramatically easier to maintain.
CNAME Lesson
Do NOT add the CNAME file before changing DNS. It causes the github.io URL to redirect to the domain which still points to Wix, creating a redirect loop. DNS change and CNAME addition must happen together.

Theme System

data-theme="dark" — dark background (#111111), white text.
data-theme="light" — light background (#F5F5F7), dark text.

Theme-aware text classes: theme-text-secondary (60% opacity), theme-text-muted (40–50% opacity).

Animation System

  • data-animate="fade-up" — fade in + slide up from below
  • data-animate="slide-right" — fade in + slide from right

One generic JS handler per type. Siblings auto-stagger. No per-section JS wiring needed.

Adding a New Section

  1. Copy the section skeleton above
  2. Pick data-theme="dark" or "light"
  3. Add an id and update nav links in <nav> and #mobile-menu
  4. Drop in standard components with data-animate attributes
  5. Done — no CSS or JS changes needed

6 Hosting & Deployment

Current Setup
Repo Optimal-Pipeline-Solutions/OPS-Website (public), branch main, GitHub Pages legacy deploy. Preview URL: https://optimal-pipeline-solutions.github.io/OPS-Website/. Production domain still on Wix.

How to Deploy Changes

  1. Edit files locally (or use the OPS Web Site Editor app)
  2. git add -A && git commit -m "description" && git push
  3. GitHub Pages rebuilds in ~30 seconds

9 Mobile / Responsive

  • Tailwind responsive prefixes (md:, lg:) handle all breakpoints
  • Mobile menu: hamburger toggles full-screen overlay with nav links
  • 100vh for hero — on iOS includes address bar space; switch to 100dvh if problematic
  • Touch scrolling on compliance horizontal scroll works natively; drag-to-scroll is mouse-only
  • SF Pro Display is native on iOS/Mac, falls back to system sans-serif on Windows

10 Content Editing

Text content is edited via the OPS Web Site Editor app (F:\OPS Web Site Editor\).

For structural changes (new sections, layout changes, animation types, color overhauls), edit the HTML/CSS/JS directly — those are Claude Code tasks, not editor tasks.
